Typing Trainer — minimal standalone app

How to run

- Open typing-trainer/index.html in your browser (no server required).
- Click the area and start typing. Use lesson select or Next/Prev to change lessons.

Features implemented

- Text area input with highlighted target text
- Real-time WPM and accuracy calculation
- Simple lesson progression and lesson select
- On-screen keyboard with key highlights and correct feedback
- Polished dark UI (CSS) inspired by keybr.com

Notes

This is a minimal, self-contained scaffold inside the repository. To serve via a local static server, run one from the repo root (e.g., `npx http-server typing-trainer -p 8080`).
