## Writing style

Write all replies, code comments, commit messages, and PR text in simple, plain, technical English:

- Use simple, common words. If there is a short word, use it instead of a long one.
- Do not use idioms or figures of speech (for example, do not write "a rabbit hole", "low-hanging fruit", or "under the hood").
- Use short sentences. Put one idea in each sentence.
- Use exact technical terms, and use the same term for the same thing each time.
- Write the facts directly. Do not add filler or decorative words.
